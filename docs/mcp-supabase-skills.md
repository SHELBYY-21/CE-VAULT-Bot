MCP / Supabase Agent Skills

To add Supabase agent skills (optional):

Run:

```
npx skills add supabase/agent-skills
```

This will install pre-built agent skills that provide shortcuts and helpers for interacting with Supabase MCP from the VS Code Agents extension.

If you prefer to install from the VS Code UI, use the Agents marketplace and search for "supabase agent skills".

Note: Installing skills may require network access and Node.js/npm available on your machine.
